CARDINAL LAW OUTLOOK SIGNATURE KIT

FILES
- Cardinal_Law_Full_Signature.html: primary signature, with address, fax, and disclaimer.
- Cardinal_Law_Reply_Signature.html: compact signature for replies (also has disclaimer).
- Cardinal_Bird_Original_Transparent.png: extracted directly from the approved gold cardinal artwork; no redraw.
- Cardinal_Bird_Original_Black.png: direct crop of the approved image on black.

QUICKEST INSTALLATION (new Outlook / Outlook on the web)
1. Unzip the full package into a permanent local folder.
2. Open Cardinal_Law_Full_Signature.html in Edge or Chrome. Select the rendered signature content (not HTML source) and copy.
3. In Outlook: Settings > Accounts > Signatures. Add a new signature, paste, save, and choose it for new mail.
4. Repeat with the Reply HTML for replies and forwards.
5. Send a test to your own external email account; confirm the bird image remains embedded, the links work, and the layout is readable on mobile.

CLASSIC OUTLOOK: File > Options > Mail > Signatures, then paste the rendered HTML content into a signature.

IMPORTANT: Keep image files next to the HTML files while previewing. Outlook's HTML paste behavior varies by version. If the image does not paste, insert the PNG using Outlook's Insert Picture command in the signature editor (not by linking to a local file), or ask IT to deploy a managed signature. The bird artwork is a raster crop of the approved image, not a new vector illustration.

All names, titles, addresses and phone numbers are editable HTML text. Use the primary signature in new emails and the compact version for replies.

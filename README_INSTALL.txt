CARDINAL LAW - CLASSIC OUTLOOK FOR WINDOWS INSTALLATION

1. In Outlook, use File > Options > Mail > Signatures. Create TWO empty signatures named exactly:
   Cardinal Law - Full
   Cardinal Law - Replies
2. Completely close Outlook (including any tray icon).
3. Press Windows+R, paste %APPDATA%\Microsoft\Signatures and press Enter.
4. Extract THIS ZIP file. Copy both .htm files and both matching _files folders into the Signatures folder. Allow replacement of the two newly created .htm files only; keep any other Outlook-created files.
5. Reopen classic Outlook. File > Options > Mail > Signatures. Choose Cardinal Law - Full for new messages and Cardinal Law - Replies for replies/forwards. If an image fails to appear, close Outlook and confirm its matching _files folder is next to the .htm file.
6. Send yourself a test message, including to a mobile account.

If your classic Outlook shows Roaming Signatures and replaces the files after reopening, disable roaming signatures only through your IT administrator's supported policy, or use a dedicated Outlook signature deployment tool. Back up your existing %APPDATA%\Microsoft\Signatures directory before replacing files.
